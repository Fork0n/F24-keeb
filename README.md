# F24-keeb
#### ever wished to have or use a keyboard with 2!!! function rows? no? well it's here anyways! by having 2 function rows with F13-F24 keys + 5 macro keys + 2 dials you can now have up to 19* customizable keys! that's like a built in streamdeck! and all of that while never leaving your keyboard! 

*assuming you remap all 12 additional function keys + 5 macros + 2 dial on click

## Project info:
### Format: TKL++
### Materials:
- case: matte Jet Black ABS
- (alt) case top: matte purple ABS
- plate: mate Ket Black Polyoxymethylene (POM)
- keycaps: to be decided
### Switches: Gateron PRO v3 BLACK or Gateron Smoothie Sea Salt
### Microcontroller: 3rd party Type C Pi Pico (RP2040)
### Firmware: Custom, RMK/QMK/VIAL based (WIP)
### Mounting Style: gasket mount

## CH I: the idea:
it all started when I got a new laptop with the nasty copilot key, at first i left it on seen and just occasionally missclicked it opening copilot, then i found out that power toys allow you to remap any key to any function (even virtual keys), that was great for muting myself on discord but i felt like i needed more. at approximately the same time i discovered that i can turn my laptop's numpad in a DIY streamdeck AKA macropad, that was still not enough. One time when i was watching a video by bringus studious i took a closer look at the infamous _dirty cherry keyboard_, instead of a mono top row it was doubled! taking and EVEN closer look revealed that the keyboard had the row folded instead of a double row. Anyways that was the time when a "double function row keyboard" idea was born.
